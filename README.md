# Katan App

> Приложение на начальной стадии.

Клиентское приложение для платформы Katan

Приложение находится на начальной стадии разработки и не будет повторять всю функциональность
основной веб-версии платформы, а предоставит ограниченный набор возможностей для удобной работы
с инфраструктурой на мобильных и десктопных устройствах

---

## Платформы

Linux, Windows, macOS, Android, iOS
